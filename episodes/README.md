# Episodes

Each numbered folder contains an independent course package.

```text
episode-XX-topic/
├── data/       # Raw source evidence and derived tables
├── html/       # Recording and teaching page
├── images/     # Generated analysis figures
├── python/     # Notebook, runnable analysis and tests
├── subtitles/  # SRT, recording script and Prompt+ text parts
└── videos/     # Final exports or recording notes
```
