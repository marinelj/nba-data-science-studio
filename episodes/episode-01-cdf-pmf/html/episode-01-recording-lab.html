Data source · the API

The API behind the stats

There is no public, documented NBA API for these numbers. The stats are served as JSON by undocumented endpoints — and an open-source package wraps them.

  1. Websitenba.com/statsplayer pages and game logs, built for people
  2. JSON endpointplayergamelogstats.nba.com/stats/playergamelog
    ?PlayerID=2544&Season=2003-04
    &SeasonType=Regular+Season
  3. Python clientnba_apicommunity-maintained, open source (MIT)pip install nba_api
  4. Our codepandas DataFrame23 rows, cached as a CSV
  • The NBA does not announce new, changed or removed endpoints, so code like this can break.
  • NBA.com has Terms of Use — read them before reusing the data.
  • Be polite: our loop sleeps 0.7 s between requests.

    Recap

    Three questions, three functions

    PDF

    Density for a continuous variable. Probability = area over an interval.

    PMF

    Point probabilities for a discrete count. “Exactly how many?” — P(X = k)

    CDF

    Probability at or below a value. “At most how many?” — F(k) = P(X ≤ k)
